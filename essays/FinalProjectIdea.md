## Overview

**The Problem:**  
Students at UH Manoa often find it difficult to connect with others romantically or socially in a meaningful way due to the lack of tailored platforms. Most existing dating apps are either too generic, not localized, or contain fake/spam accounts. They also often emphasize looks over personality, and students may feel uncomfortable engaging with people outside of their campus community. With no dating platform catering specifically to UH Manoa, there’s a clear gap for an app that is both secure and community-oriented.

**The Solution:**  
We propose the development of **“Rainbae”**, a UH-exclusive dating app inspired by Hinge that is only accessible to verified UH Manoa students and faculty. Rainbae will allow users to build detailed profiles using photo uploads and prompt-based questions (e.g., "What’s your favorite spot on campus?" or "Describe your ideal UH weekend"). The app will offer matching based on mutual likes and shared interests. In-app messaging will allow matched users to communicate safely, while profile visibility and interaction history remain private. All accounts will be authenticated using @hawaii.edu emails to ensure a trusted community.

## Mockup Page Ideas

1. **Landing Page**  
   - App branding and introduction to Rainbae  
   - Login and registration buttons  
   - Brief explanation of how it works ("Connect with real UH students.")

2. **Registration & Verification Page**  
   - Enter @hawaii.edu email  
   - Receive verification code  
   - Set up basic account info: name, age, gender, orientation

3. **Profile Setup Page**  
   - Upload up to 6 profile pictures  
   - Answer 3 of 6 fun personality prompts (customized for UH, e.g., “Best memory from Campus Center,” “Favorite local food truck”)  
   - Select preferences: age range, interests, majors, dating intent

4. **Explore/Discover Page**  
   - Card-style layout (like Hinge) to scroll through profiles  
   - Heart specific parts of a profile (a prompt answer or picture)  
   - Daily "UH Spotlight" match suggestion

5. **Matches & Messaging Page**  
   - List of current matches with last message preview  
   - Real-time chat with typing indicators  
   - Optional UH-themed emojis/stickers

6. **Profile Page (User Settings)**  
   - Edit profile, change photos and prompts  
   - See liked profiles and received likes  
   - Set visibility (e.g., hide profile temporarily)  
   - Logout or delete account

## Use Case Ideas

- As a student, I want to create a profile that reflects my UH Manoa experience and personality so I can attract meaningful connections.
- As a user, I want to filter matches by interests, age, year, and major to find more relevant connections.
- As a user, I want to be able to message my matches within the app, so I don’t have to give out personal contact information.
- As a user, I want to be able to like specific profile answers or photos, so I can express interest genuinely.
- As a user, I want to be sure I’m only seeing real UH Manoa students/faculty, so I feel safe using the app.
- As a user, I want to receive daily recommendations so I don’t feel overwhelmed by unlimited swiping.

## Beyond the Basics

**Special Sauce:**  
Each Rainbae user will have a dynamic, personalized profile based on their answers to custom prompts. The app’s matching algorithm will consider shared prompt responses and preferences to suggest connections. Users will have access to their match history, favorites, and profile insights (e.g., how many likes received). The "like specific part of a profile" feature adds nuance to the matching process and makes connections more meaningful.

**UH Manoa Focus:**  
Rainbae is built exclusively for UH Manoa, with registration limited to verified @hawaii.edu emails. The profile prompts, stickers, and themes will be UH-centric. For example, prompts like “Best poke spot near campus” or “Would you rather study at Hamilton Library or on the beach?” ensure the experience feels locally grounded. Stickers might include Mānoa rainbows, Bows logos, and shakas.

**Extra Features:**
- “Rainbow Recap” – weekly email summary of new likes/matches  
- “Crush Hour” – daily 1-hour window when new profiles are highlighted to all users  
- Anonymous “Icebreaker Generator” to help start conversations  
- Accessibility settings (dark mode, font size, etc.)  
- Moderation/reporting tools to handle misconduct or fake profiles
